# UTS Pengantar Sains Data: Statistik Deskriptif in R

Analisis statistik deskriptif harga komoditas dan cuaca Kota Singkawang (Januari 2016 sampai Desember 2023) menggunakan R.

- Laporan RPubs: https://rpubs.com/satriarmdhn/1467255
- Sumber data: https://data.mendeley.com/datasets/79bmb9vkwk/3

## Isi repo
- `dataset.xlsx`: data mentah
- `UTS_Statistik_Deskriptif.Rmd`: kode dan laporan
- `UTS_Statistik_Deskriptif.docx`: laporan dalam format Word
